# Simple Chat (Vue 3 + TypeScript + Vite)

This is a small chat app frontend made with Vue 3, TypeScript and Vite.

What it does:

- Show list of channels
- Create / join / leave channels
- See messages in a channel and send messages (using socket)
- Simple user auth (login / register)

1. Need Node.js.
2. Open terminal in this project folder.
3. Install packages:

```bash
npm install
```

4. Start the app (dev server):

```bash
npm run dev
```
